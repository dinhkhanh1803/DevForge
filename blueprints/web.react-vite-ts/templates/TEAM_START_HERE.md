# Team start here

## First-day checklist

1. Read `ARCHITECTURE.md` before changing boundaries.
2. Use the certified Node/pnpm ranges and frozen script-disabled install command.
3. Configure only public `VITE_` values through an untracked `.env`.
4. Run all commands in `TESTING.md` before review.
5. Follow `CONTRIBUTING.md`; review `DEPLOYMENT.md` before release work.
