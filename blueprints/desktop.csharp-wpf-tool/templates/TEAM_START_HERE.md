# Team start here

## First-day checklist

1. Read `ARCHITECTURE.md` and preserve the inward dependency direction.
2. Install the .NET 10 SDK and run the commands in `DEVELOPMENT.md`.
3. Run every gate in `TESTING.md` before opening a review.
4. Keep configuration non-sensitive and never commit `.env` or credentials.
5. Use `CONTRIBUTING.md` for change discipline and `DEPLOYMENT.md` for release preparation.
