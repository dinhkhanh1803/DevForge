# Team start here

## First-day checklist

1. Read `ARCHITECTURE.md` before changing package boundaries.
2. Use CPython 3.14, uv 0.12, and the frozen config-isolated sync command.
3. Configure only documented process variables; never commit `.env`.
4. Run all commands in `TESTING.md` before review.
5. Follow `CONTRIBUTING.md` and review `DEPLOYMENT.md` before release work.
