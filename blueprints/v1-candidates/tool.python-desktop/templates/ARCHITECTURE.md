Tk/ttk widgets to the model on the UI thread. desktop_cli.py composes configuration,

## Decisions
The standard-library Tk GUI avoids runtime third-party GUI dependencies.
Preserve this separation when adding application services. Never block the UI
thread with long-running work; marshal results back to Tk's event loop.
