Native Python Desktop candidate generated by DevForge Studio.

## Prerequisites
Windows, Python 3.14 with Tcl/Tk and uv 0.12. No automatic interpreter installation.
Dependencies are pinned in pyproject.toml and uv.lock.

## Quick start
```text
uv sync --frozen --no-config
uv run --frozen --no-sync --no-config team-desktop
```
Use Refresh status or Alt+R. Close the window normally. No network or file writes
occur in the view. Configure logging with the values in .env.example; the app
does not load .env automatically.

## Quality gates
Follow TESTING.md before committing. Native smoke must pass on the actual release
host. This source package is not a standalone executable or installer.
