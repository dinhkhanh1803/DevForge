# {{ project.name }}

Native Python Desktop candidate generated by DevForge Studio.

## Local setup
Run uv sync --frozen --no-config with Python 3.14 and Tcl/Tk installed.
Run uv run --frozen --no-sync --no-config team-desktop to open the GUI.
Use .env.example as a reference; no .env loader or database is configured.

## Debug
Set breakpoints in desktop_cli.py and model.py with the project .venv interpreter.
Tk event callbacks must stay on the main thread. Missing Tcl/Tk is an environment
failure, not a reason to skip native acceptance. No Docker or cloud service is needed.
