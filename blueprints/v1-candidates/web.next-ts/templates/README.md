# README

## Project

{{ project.name }} is a Next.js App Router TypeScript starter. The home page and
/api/health route run locally; there is no external API, authentication or database.

## Quick start

Install reviewed Node 22.23.2 and pnpm 10.24.0, then run:

```text
pnpm install --frozen-lockfile --ignore-scripts
pnpm run dev
```

The dev server binds to 127.0.0.1. See TEAM_START_HERE.md before changing the project.
